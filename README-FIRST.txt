NUCLEARSHIELD EXAM CONSOLE
==========================

THIS IS THE EXAM ML + TARGETS + AUDIT FIX BUILD. The AI Detection page
shows all scored observations, an ML demonstration button, and reasons
when input is insufficient. Use the new ZIP's extracted folder, not an earlier extracted project folder.
The model runs on a NEW upload containing at least 20 suitable numeric
network rows; older analysis history is not silently reprocessed.

Extract the entire ZIP to a normal folder. On Windows, double-click
START-NUCLEARSHIELD.cmd with Docker Desktop running. The launcher selects
free app, Prometheus and Grafana ports; opens the complete web platform;
and keeps the terminal window open to display actual application requests
and lightweight browser navigation / hover context.

The initial launch must download missing monitoring images and build the
application image. Later launches reuse the cached app image until the
application source changes. Image downloads still depend on network speed.

Hover reports UI context only. Actual data processing occurs on upload,
analysis and API requests. The backend logs those requests independently.
No facility systems or control devices are connected.

On Monitoring > Targets, use the browser links (including Open Prometheus
targets). The Docker scrape address nuclearshield:8000 is internal only.
In Audit, each live analyzed file has a Delete analyzed file button; its
audit history stays as a record after deletion.

Assurance Lab demonstrates a finite one-way gateway policy and human review
gate, offline PACS/MC&A joins, and repeated integrity snapshot comparison.
Upload sample-data/NuclearShield-Full-Platform-100-Records.jsonl, then
sample-data/08-later-integrity-snapshot.csv to see the snapshot comparison.
These checks use synthetic uploads only; no live nuclear device or PACS is
connected, and no safety software is formally verified.

Next, while the full-platform file is selected, open Assurance Lab and click
Run training catalog. The synthetic offline indicator JSON produces
evidence-linked exact-match examples and a human review checklist. No live threat-intelligence
feed, autonomous containment or plant endpoint is used.

Compliance and Reports offer a per-analysis evidence packet JSON export with
SHA-256 references, safeguards review counts and the linked audit events.
It is a local training packet, not a report accepted by a regulator.

Do not run the CMD directly inside a compressed ZIP: Windows may extract
only the launcher file instead of the whole project.
