NUCLEARSHIELD - START HERE

Windows quick start
1. Install and open Docker Desktop.
2. Wait until Docker Desktop reports that the engine is running.
3. Double-click START-NUCLEARSHIELD.cmd.
4. NuclearShield opens automatically in your browser.

The first run downloads a monitoring image only when it is missing. Later runs
reuse the installed images without pulling them again. If a preferred port is
busy, the launcher automatically selects another free port and updates the
Monitoring links.
