# Security and Safety Boundary

NuclearShield is an educational, defensive simulation. It must not connect to real nuclear facilities, production SCADA/PLC devices, safety instrumentation, access-control hardware, or nuclear material accounting systems.

The project intentionally uses synthetic telemetry and simulated events. Do not add exploit chains, destructive industrial commands, credential theft, persistence, evasion, malware, or instructions for bypassing physical/cybersecurity controls.

Report software vulnerabilities through a private maintainer channel rather than publishing sensitive proof-of-concept details.
