# Security policy and safe-use boundary

NuclearShield is a defensive educational demonstrator. Do not connect it to a nuclear facility, industrial control network, safety system, physical-access system, material-accounting system or production telemetry source.

The repository deliberately contains no real plant topology, credentials, vulnerabilities, exploit logic, control commands, process set points, personnel records or nuclear material information. The sample records are fictional.

Report a repository vulnerability privately to the maintainer. Do not include operational nuclear or sensitive facility data in a report.
